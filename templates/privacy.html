Privacy & Security

Learn how WearableLens AI protects your privacy and handles your data securely.

Data Protection

No Account Required

WearableLens AI does not require user accounts, login credentials, or personal registration to use our services.

Image Handling

• Images are processed in real-time and not permanently stored by default

• Uploaded images are automatically deleted after analysis (typically within 1 hour)

• No image data is shared with third parties without explicit user consent

AI Analysis Privacy

• AI analysis is performed through external providers (OpenAI, Google Gemini) when configured

• Users are informed when AI providers receive their images

• All API communications are encrypted (HTTPS only)

Security Measures

Technical Safeguards

• End-to-end encryption for all data transmissions

• Secure API key management (environment variables only)

• Rate limiting to prevent abuse

• Input validation and file type restrictions

• Regular security audits and updates

User Control

• Manual search mode available when AI providers are not configured

• Transparent information about data processing

• Clear explanation of AI limitations and manual search guidance

Your Rights

Data Control

• You control what data you upload

• You can delete your data by clearing browser cache or requesting deletion

• No persistent tracking or cookies for analysis purposes

Transparency

• Clear explanation of how images are processed

• Information about AI provider usage and limitations

• Manual fallback when AI is unavailable
